問題文： 画像をダウンロードして、flagを見つけてみよう。

とりあえず問題文にあるファイルをダウンロードしよう！！
次は、ダウンロードしたファイルの種類を調べよう！！
拡張子が.pngだからpngファイルつまり、画像ファイルかも？？

ファイルの種類を調べるからfileコマンドを使おう！！
![](/images/writeup7.png)

この結果からファイルがpngファイル、つまり画像ファイルであることが分かりました。
次に、何か読める文字が無いか調べるためにstringsコマンドを使います。
grepコマンドで"pico"  "ctf"  "flag" 　を大文字小文字関係なく調べてみよう！！
-i ➡ 大文字小文字関無視できるオプション
![](/images/writeup8.png)

この結果から読める文字にflagは無さそうだな。
次は、画像を実際に表示しみよう！！
![](/images/writeup9.png)

画像を見ると特にflagを見つけることはでき無さそう。
次は、バイナリを16進数に変換するコマンドであるxxdコマンドを使って、バイナリファイルの中身を見てみよう！！
バイナリファイルとは？？
↪人間には読めない０と１で構成されているファイルのこと。
![](/images/writeup10.png)

この後、grepコマンドでctfやpicoなどのキーワードを絞ったが、flagは出てこなかった。
次は、binwalkコマンドを使って、ファイルの中に埋まっている別のファイルが埋まっていないか探してみよう！！
別のファイルが埋まっていたらそこにflagがあるかも😏
![](/images/writeup11.png)

この結果から特に怪しいファイルはないことが分かった。

次は、ステガノグラフィを使ってみよう！！
ステガノグラフィとは、画像や音声や動画の中にメッセージが隠されていないか見る技術のこと。
なんかかっこいい！✌✌
ステガノグラフィのコマンドはzstegコマンドです。
zstegコマンドのダウンロードの仕方
sudo apt update
sudo apt install zsteg

zstegコマンドを使ってステガノグラフィを見てみよう！！
![](/images/writeup12.png)

この結果を見ると画像の中にflagがあることが分かりました。
よって、答えは、picoCTF{7h3r3_■■■■■■■■■■■■■■■■■■■■}であることが分かりました。
